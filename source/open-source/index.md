The following lists self-identified open source tools and libraries. To be added, please fill out the [form](https://goo.gl/forms/P73lgzabKbOb21Qp2).

|  |  |
| --- | --- |
| [Photon](https://github.com/Netflix/photon) | IMF Package validation |
| [ASDCPlib](http://www.cinecert.com/asdcplib/) | IMF Track File creation and parsing |
| [imscJS](https://github.com/sandflow/imscJS) | IMSC1 subtitle and caption rendering |
| [IMF Conversion](https://github.com/DSRCorporation/imf-conversion) | Converts IMF to DPP and iTunes deliverables |
| [IMF Tool](https://github.com/IMFTool/IMFTool) | Open Source Tool for browsing and editing of IMF App #2/#2E packages. Binary installers available for macOS and Windows. |
| [regxmllib](https://github.com/sandflow/regxmllib) | Converts MXF Essence Descriptors to the XML representation specified in SMPTE ST 2001-1 |
| [Timed Text Toolkit](https://github.com/skynav/ttt) | IMSC1 document validation |
| [DTS IAB Validator](https://github.com/DTSProAudio/iab-validator) | Validates IA bitstreams against SMPTE ST 2098-2, ST 2098-2 and ST 2067-201 as well as other specifications. |
| [OpenJPEG](https://github.com/uclouvain/openjpeg) | JPEG 2000 encoder and decoder |
| [FFmpeg](https://ffmpeg.org/) | A complete, cross-platform solution to record, convert and stream audio and video |
| [bmx](https://github.com/ebu/bmx) | Creates and manipulates MXF files, including IMF Track Files. Windows and macOS binaries available. |
